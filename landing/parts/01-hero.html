Close the lid,
Claude stops.
Claude keeps working.

ClaudeKeeper is a tiny local daemon that holds your Mac awake — even with the lid shut — so Claude Code keeps running after you step away. It holds a sleep assertion, then flips pmset disablesleep so the machine stays fully awake: screen off, your session still going. Honest about it: run it on AC, and don't cook a closed Mac in a bag.
