Keep Claude working when you close your Mac.

ClaudeKeeper is a small macOS daemon that stops your Mac from sleeping — including with the lid closed — so a Claude Code session keeps running after you step away. It holds a sleep assertion and sets pmset disablesleep, then restores everything when you stop.

How it works

Two macOS behaviors, handled honestly. Idle sleep needs no privileges. Lid-close sleep does — and nothing but the setting below actually overrides it.

01

Start the daemon

Run claudekeeper daemon start. A small local daemon runs independent of your terminal and prints the port it serves on. Close the terminal — it keeps running.

02

Idle sleep is held off

It holds a real sleep assertion (a native IOKit assertion, or caffeinate) so the Mac never idle-sleeps. You can see it in pmset -g assertions. No sudo required.

03

Lid close is the real fix

Closing the lid forces sleep, and no idle assertion overrides that. ClaudeKeeper runs sudo pmset -a disablesleep 1 — the one setting that keeps the machine fully awake with the lid shut. It's restored to 0 on stop, and resets on reboot.

The honest caveat. A closed Mac that never sleeps generates heat with the lid down. Run it on AC power, and don't leave it working full-tilt in a closed bag. Prefer idle-sleep prevention only? Start with --no-lid and skip the sudo prompt.

Commands

The whole surface is three commands. No config to learn.

claudekeeper daemon start Start the daemon and keep the Mac awake, including with the lid closed. Prints the port.
claudekeeper daemon stop Stop the daemon and restore normal sleep.
claudekeeper uninstall Stop, restore sleep, and remove ClaudeKeeper.
