ClaudeKeeper GitHub

Keep Claude working while you step away.

Your Mac sleeps a few minutes after you leave — and takes your Claude Code session with it. ClaudeKeeper keeps it awake so long runs keep going. No admin, no fuss.

$ npm install -g @rangan23/claudekeeper

claudekeeper
$  
✓ daemon running on http://localhost:7642
✓ your Mac won't sleep while you're away

Three commands. That's it.

Start it when you're heading out, stop it when you're back.

claudekeeper daemon start Start it and keep your Mac awake while you're away.
claudekeeper daemon stop Stop it and let your Mac sleep normally again.
claudekeeper uninstall Remove it completely.
